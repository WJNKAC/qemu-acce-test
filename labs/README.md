## 关键结论（一句话）

ARM 的 `CPU_INTERRUPT_HARD` 唯一清零点在 `arm_cpu_set_irq(level=0)`，
即 GIC 拉低线的一刻。这隐含"GIC 与投递者同栈"。henge 嫁接打破了这个前提，
所以必须让电平只有一个所有者 —— 引擎读穿透 QEMU 的 flag，与 MTTCG 同款。

## 判定三件套

| 信号 | 含义 |
|---|---|
| CPU 100% + `A` 疯涨 + `slept` 冻结 | 活锁 |
| CPU 0% + `in-park` ≥ 1 冻结 | park 死锁 |
| `sendkey` 无响应 + `wake` 冻结 | 客机卡死 |
